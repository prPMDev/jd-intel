Setup & usage guide

Install jd-intel in your AI client, learn what to ask, and fix the common snags. New here? Start on the home page.

Setup

Works with any MCP-aware AI client: Claude Desktop, Claude Code, Cursor, Windsurf, VS Code. ChatGPT, Gemini, and other non-MCP clients do not support this yet (they use different tool-calling systems).

Claude Desktop (one-file, no terminal)

The simplest path. No terminal, no Node.js: Claude Desktop runs the server on its own bundled runtime.

  1. Download the jd-intel extension (a .mcpb file).
  2. In Claude Desktop, open Settings, then Extensions, then Advanced settings, and click Install Extension. Pick the file you downloaded.
  3. Review the access summary, click Install, then start a new chat. The tools appear automatically.

Shortcuts: you can also drag the .mcpb onto the Settings window, or double-click it when your system opens .mcpb files with Claude Desktop. The extension is open source and unsigned, so Claude Desktop shows an "unverified" notice. Choose Install Anyway.

Claude Desktop (command line)

Prefer the terminal, or on an older Claude Desktop? You'll need Node.js 18 or newer first (check with node --version).

  1. Open Terminal (macOS) or PowerShell (Windows). It's just a text window. Nothing destructive happens.
  2. Paste this and hit Enter: 
    npx jd-intel-mcp install
  3. Quit and reopen Claude Desktop. The tools appear automatically.

Other clients (Claude Code, Cursor, Windsurf, VS Code)

One-click .mcpb install is a Claude Desktop feature. These clients run the same server, defined as command: "npx", args: ["-y", "jd-intel-mcp"], and need Node.js 18+. Only the wrapper differs:

  • Claude Code: run claude mcp add jd-intel -- npx -y jd-intel-mcp.
  • Cursor: add it under mcpServers in ~/.cursor/mcp.json (or Settings, Tools & MCP). See docs.cursor.com.
  • Windsurf: add it under mcpServers via Settings, Tools, Add Server. See docs.windsurf.com.
  • VS Code (Copilot agent): add it under servers with "type": "stdio" in .vscode/mcp.json.
{
  "mcpServers": {
    "jd-intel": {
      "command": "npx",
      "args": ["-y", "jd-intel-mcp"]
    }
  }
}

VS Code uses a servers key with "type": "stdio" instead of mcpServers.

Manual config for Claude Desktop (fallback)

If the one-command install fails, edit Claude Desktop's config file directly:

  • macOS: ~/Library/Application Support/Claude/claude_desktop_config.json
  • Windows: %APPDATA%\Claude\claude_desktop_config.json
{
  "mcpServers": {
    "jd-intel": {
      "command": "npx",
      "args": ["-y", "jd-intel-mcp"]
    }
  }
}

Restart Claude Desktop after editing.

Confirm it's working

Start a new chat and ask: "What fintech companies are in your jd-intel registry?" If it lists companies, you're set. Then try the real thing: "Find senior PM roles open right now that I'd be a fit for." Not seeing the tools? See Troubleshooting.

Using jd-intel

jd-intel fetches. Your AI thinks. Ask in plain language; your assistant calls the tools and reasons over the results with everything it already knows about you.

Things to ask

  • "What senior PM roles are open right now that I'd be a fit for?" → jd-intel pulls current openings, your AI ranks by your background.
  • "Show me design lead roles open at fintechs." → jd-intel sweeps the sector, your AI filters by what fits.
  • "Find engineering roles at series-B startups that match my background." → jd-intel sweeps the registry, your AI ranks by fit.
  • "Compare scope across the four staff PM roles I'm looking at." → jd-intel pulls each JD, your AI maps the differences.

What you can do

  • Look up open roles at any supported company, no copy-paste.
  • Tailor your resume across several roles in one conversation.
  • Rank openings by fit with your background.
  • Scan a whole sector: "Pull open roles at fintech companies posted this week."
  • Research teams by reading their job descriptions in bulk.

The tools your AI calls

  • fetch_jobs: get a company's open roles, with filters for role type, topic, location, and recency.
  • search_registry: find supported companies by name or sector.
  • detect_ats: identify which hiring platform a company uses.

Filtering

Filters narrow what comes back. They AND together.

  • title: matches the job title only (role identity: PM, engineer, designer).
  • topic: matches title, department, and description (scope: integrations, growth).
  • posted within days: recency cuts.
  • location include / exclude: region targeting.
  • limit: cap the number of results.

Full design notes and gotchas: filter reference.

Troubleshooting & maintenance

Tools not appearing?

  • Fully quit and reopen the client (quit, do not just close the window). Claude Desktop: system tray then Quit on Windows, or ⌘Q on macOS.
  • For npx clients (Claude Code, Cursor, Windsurf, VS Code), run npx clear-npx-cache, then restart.
  • Confirm node --version is 18 or newer for the npx paths. The one-click .mcpb does not need Node.
  • Check the client's MCP or error log for a startup message. jd-intel logs a line like [jd-intel] runtime check: Node v20... when it starts.

"Unverified" warning at install

Expected. The extension is open source and unsigned, so Claude Desktop flags it. Choose Install Anyway. The source is on GitHub if you want to read it first.

Am I current?

Every result includes the running version in its metadata, so you can ask your AI "what version of jd-intel are you running?" The company registry refreshes on its own: jd-intel fetches the current list at startup and falls back to the bundled copy offline, so new companies show up without reinstalling.

Updating

The one-click .mcpb does not auto-update. To move to a newer version, download the latest .mcpb and install it over the current one. The npx path updates on its own: each restart runs the published version from npm. Library or CLI: npm install jd-intel@latest.

Uninstalling

Claude Desktop extension: remove it under Settings, then Extensions. Command-line install: run npx jd-intel-mcp uninstall, then restart Claude Desktop.
