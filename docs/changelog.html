What your AI can search now.

23 Aug 2026 Latest

47% more companies. 355 to 522.

Energy and industrial grew most, up 200%. Healthcare and life sciences up 173%, gaming up 105%. European coverage about doubled, mostly Dutch, German and Nordic employers. Five weeks of runs landed at once.

WHOOP, Nubank, CareMessage, Planhat and Sendcloud all switched hiring platform. They point at the new one now, so they still turn up when you search.

How this is verified

A company only gets added if its hiring board is live and returning open roles. Every cycle re-checks the whole registry, which is how the five moves above turned up. Boards also go quiet, so some entries come back empty on a given day. Run npm run verify:registry to see where things stand, or open the pull requests.
